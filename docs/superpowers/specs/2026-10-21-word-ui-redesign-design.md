# 论文阅读器 Word 风格界面重组设计

日期：2026-10-21
状态：已确认（强调色 C 中性石墨）
范围：仅前端界面重组，不改解析、批注、导出后端逻辑

## 1. 背景与目标

现有阅读器是轻量 ribbon + 三栏结构，功能完整但入口分散、层级扁平，与桌面阅读工具的肌肉记忆不一致。本次按 Microsoft Word 的信息架构重组界面，让「导入—阅读—批注—图表解析—视图控制」各自有明确归属，同时保留全部现有能力与 DOM id，避免回归。

目标：

1. 建立 Word 式外壳：标题栏、页签、分组 Ribbon、Backstage、状态栏。
2. 按 Word 习惯重新分配功能入口，减少同一操作在多处出现。
3. 界面强调色统一为中性石墨（C 方案），弱化品牌色，保持学术工具的克制观感。
4. 不引入前端框架，继续使用原生 ES Module + 静态 SPA。

非目标：

- 不改动图表检测、按需解析、墨迹/文本批注、导出 PDF 的实现。
- 不做最近文件列表、多文档标签、打印、排版编辑。
- 不新增除 Esc 关闭 Backstage 外的快捷键。

## 2. 视觉系统（中性石墨）

设计令牌定义在 `styles.css` 的 `:root`：

| 令牌 | 值 | 用途 |
|---|---|---|
| `--w-accent` | `#5B5B5B` | 强调色、选中下划线、焦点框 |
| `--w-accent-strong` | `#3C3C3C` | 主要按钮描边、激活图标 |
| `--w-text` | `#242424` | 主文本 |
| `--w-text-muted` | `#6B6B6B` | 次要文本、组名 |
| `--w-chrome` | `#F3F2F1` | 标题栏、页签条、状态栏 |
| `--w-surface` | `#FFFFFF` | Ribbon、侧栏、Backstage 面板 |
| `--w-canvas` | `#E9E8E6` | 阅读画布底色 |
| `--w-border` | `#E1DFDD` | 分隔线 |
| `--w-hover` | `#EDEBE9` | 悬停填充 |
| `--w-focus` | `#5B5B5B` | 2px 焦点描边 |

标注内容色不随界面变化：墨迹默认 `#CC2936`，仍可由颜色选择器修改；图表框与批注锚点改用石墨描边，避免与标注内容混色。字体沿用系统 UI 字体栈，标题不再使用衬线体（与 Word 外壳一致）。

## 3. 界面骨架

```
┌ 标题栏：应用名 · 文件名 | 快速访问(撤销/重做/导出) | 模型健康灯 ┐
├ 页签：文件  开始  批注  图表  视图  工具箱 ────────────────────┤
├ 分组 Ribbon（组间竖分隔 + 底部组名，可折叠）───────────────────┤
├ 缩略图栏 │ 阅读画布（页面/图框/墨迹/批注层） │ 右栏(批注/图表/工具箱) ┤
└ 状态栏：页码 · 图表数 · 批注数 | 窗格开关 · 缩放滑块/百分比 ────┘
```

- 标题栏高 32px，页签条高 32px，Ribbon 展开高约 88px，状态栏高 26px。
- 右栏宽 300px，缩略图栏宽 148px，均可隐藏；画布区域自适应剩余空间并保持现有缩放/适应逻辑。
- 翻页按钮从画布下方浮动条移入状态栏，保留 `#btn-prev`、`#btn-next`、`#page-indicator` 三个 id。
- 阅读画布不再显示「上一页/下一页」浮动条，减少与 Word 状态栏翻页的重复。

## 4. 页签与命令归属

「文件」点击打开 Backstage 覆盖层（不切换 Ribbon 面板），其余页签切换分组 Ribbon。

| 页签 | 分组 | 命令 | 来源 / 可用条件 |
|---|---|---|---|
| 文件 | 打开 | 导入论文（`#btn-import` + `#file-input`） | 始终可用 |
| 文件 | 导入选项 | 检测图表并标记（`#chk-detect`） | 始终可用，默认勾选 |
| 文件 | 输出 | 导出带标注副本（`#btn-export`） | 已导入论文 |
| 开始 | 注释 | 笔/荧光笔/橡皮/批注（`data-tool`） | 已导入论文；当前工具高亮，再点回到阅读 |
| 开始 | 注释 | 颜色（`#ink-color`）、粗细（`#ink-width`） | 已导入论文 |
| 开始 | 编辑 | 撤销（`#btn-undo`）、重做（`#btn-redo`） | 有对应栈 |
| 开始 | 导航 | 上一页/下一页（`#btn-prev`/`#btn-next`） | 已导入论文 |
| 批注 | 墨迹 | 笔/荧光笔/橡皮/批注 | 同「开始」，复用命令 |
| 批注 | 管理 | 清空本页（`#btn-clear-page`） | 当前页有墨迹 |
| 批注 | 窗格 | 批注窗格开关（`#btn-toggle-comments`） | 已导入论文 |
| 图表 | 检测 | 检测状态（`#detect-status`）、重新检测（`#btn-redetect`） | 重新检测：已导入且后端健康 |
| 图表 | 导航 | 图表清单（按页列出 `p{页}-f{n}`，点击跳页并打开图表窗格） | 检测到图表 |
| 视图 | 显示比例 | 适应宽度（`#btn-fit-width`）、适应页面（`#btn-fit-page`）、缩放（`#zoom-select`） | 已导入论文 |
| 视图 | 窗格 | 缩略图窗格开关（`#btn-toggle-thumbs`）、批注窗格开关 | 已导入论文 |
| 视图 | 窗口 | Ribbon 折叠（`#btn-ribbon-collapse`） | 始终可用 |
| 工具箱 | 单图解析 | 打开工具箱（`#btn-show-toolbox`） | 始终可用，切到右栏工具箱页签 |

备注：撤销/重做按钮同时出现在标题栏快速访问区与「开始」页签，二者绑定同一命令。

## 5. 交互细节

1. **Backstage**：点击「文件」打开覆盖层，左侧竖排「打开 / 导出 / 关于」，右侧为对应内容区；Esc、左上角返回箭头或点击遮罩关闭。导入与导出沿用现有元素 id，元素整体移入 Backstage，不再额外创建重复控件。
2. **Ribbon 折叠**：双击页签条任意位置或点击右上角折叠按钮切换。折叠后仅显示页签，点击页签临时展开并切换该页签；折叠状态持久化。
3. **窗格显隐**：缩略图与右栏通过「视图」开关；右栏内的「批注/图表/工具箱」页签保持现有行为。关闭右栏后，解析图表或新建批注会自动打开右栏对应页签。
4. **状态栏**：左侧显示「第 x 页 / 共 y 页 · z 张图表 · c 条批注」；右侧为窗格开关图标、缩放减/加按钮、滑块与百分比。缩放与 `#zoom-select` 双向同步。
5. **空状态**：未导入时画布显示 Word 式空白文档卡「导入论文开始」，快速访问区与状态栏计数置灰。
6. **持久化**（localStorage）：`reader.ui.activeTab`、`reader.ui.ribbonCollapsed`、`reader.ui.thumbsVisible`、`reader.ui.sidebarVisible`。读取失败时回退默认值，不阻塞初始化。
7. **响应式**：宽度 < 1120px 时缩略图栏默认隐藏（用户手动开启仍生效），右栏保持 300px；标题栏文件名超长省略号截断。

## 6. 代码结构与数据流

新增两个模块，其余模块只做最小接入：

- `js/commands.js`：命令注册表。`register(name, {run, enabled})`、`run(name)`、`setEnabled(name, ok)`、`refreshStates()`。不直接操作 DOM，不知道按钮位置。
- `js/shell.js`：外壳控制。负责页签/Backstage/折叠/窗格/状态栏/localStorage，把 `data-cmd` 按钮委托给 `run(command)`，并订阅事件刷新计数与命令可用态。

改造：

- `index.html`：新增标题栏、`文件/开始/批注/图表/视图/工具箱` 页签与分组 Ribbon、状态栏、Backstage；移动现有控件（保留 id），新增 `data-cmd` 属性。
- `styles.css`：以令牌重写外壳样式；保留画布、图框、墨迹、批注锚点、toast 的原有几何规则。
- `js/ribbon.js`：从「散落事件监听」改为「注册命令 + 绑定 `data-cmd`」；工具高亮与健康灯逻辑保留。
- `js/figures.js`：加载、重新检测、解析状态变化后新增 `emit('figures-updated')`。
- `js/main.js`：初始化顺序 `initCommands → initShell → initViewer → initFigures → initInk → initComments → initRibbon → initToolbox`。
- 其余模块（viewer/ink/comments/toolbox/api）不改业务逻辑。

事件与状态流：

- 现有事件：`paper-loaded`、`page-changed(n)`、`scale-changed`、`annotations-changed`、`switch-side-tab(name)`。
- 新增事件：`figures-updated`、`tool-changed(tool)`（供多处工具按钮同步高亮）。
- 数据来源：`state.paper.n_pages`、`state.page`、`state.figures`、`state.annotations`；shell 只读取，不写入业务状态。

命令可用态规则：

- 无论文：导入可用；导出、翻页、注释工具、视图缩放、重新检测禁用。
- 有论文：导出、翻页、注释工具、视图缩放可用；重新检测额外要求健康灯为绿。
- 撤销/重做：根据 ink 模块的栈深更新（通过 `annotations-changed` 后调用 `refreshStates()`）。
- 清空本页：当前页有笔画时可用。

## 7. 错误处理

- 后端不可达或模型缺失：标题栏健康灯变红，`重新检测` 禁用，tooltip 给出启动命令与 `CHART_SDK_MODEL` 提示；恢复后自动重新启用。
- 检测进行中：状态栏显示「检测中 x/y」，`重新检测` 禁用；失败时「图表」分组显示失败原因，仅保留阅读能力。
- 导出失败、解析失败：沿用 toast 与右栏错误文案，不新增弹窗。
- Backstage 未导入时导出项置灰并提示「请先导入论文」。

## 9. 风险与取舍

- **DOM id 保留**：外壳重排会改动 DOM 层级，但所有既有 id 不变，降低测试与回归风险；新控件统一使用新 id。
- **样式重写**：`styles.css` 大范围改动可能影响画布几何（图框/墨迹坐标依赖 `#page-stage` 尺寸）。应对：画布相关规则不改，只替换外壳与颜色令牌，截图逐项比对。
- **重复入口**：撤销/重做与工具在标题栏/开始/批注出现多次，用命令注册表保证行为一致。
- **石墨强调色对比度**：按钮选中态使用「石墨文字 + 浅灰底 + 2px 左/下描边」，避免仅靠颜色区分；焦点框保留 2px 描边满足键盘可见性。
